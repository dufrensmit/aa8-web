Exercício 1. Implemente

Crie uma função calculadora, que recebe 3 parâmetros: valor a, valor b e uma função que fará o cálculo (chamada de f).

A chamada dessa função calculadora deve retornar o retorno de f quando recebe os parâmetros a e b

Crie também duas funções, soma e subtrai. Ambas recebem dois valores como parâmetro e retornam a soma e a subtração dos valores, respectivamente.

Imprima no console o valor retornado pela função calculadora passando os sequintes parâmetros:

  • a=31, b=12, f=soma
  • a=11, b=25, f=subtrai

function calculadora(a, b, f) {
    return f(a, b);
}

function soma(a, b) {
    return a + b;
}

function subtrai(a, b) {
    return a - b;
}

console.log(calculadora(31, 12, soma));     // 43
console.log(calculadora(11, 25, subtrai));  // -14

Resposta: a calculadora delega a operação para a função recebida. Os resultados são 43 e -14.

Exercício 2. Qual a saída no console?

var callback = function() {
    console.log("Estou na função de callback");
}    
console.log("Iniciei")
setTimeout(callback, 5000);
console.log("Estou após o setTimeout")

Resposta: primeiro aparecem Iniciei e Estou após o setTimeout, nessa ordem. Após aproximadamente 5 segundos, aparece Estou na função de callback. O temporizador agenda o callback e não bloqueia a execução seguinte.

Exercício 3. Qual a saída do console?

function consoleAtrasado(mensagem, atraso) {
    setTimeout(console.log(mensagem), atraso)
}
console.log("Olá")
consoleAtrasado("Teste", 10000)
console.log("Bye")

Resposta: Olá é impresso primeiro. Ao chamar consoleAtrasado, console.log("Teste") é executado imediatamente e seu retorno (undefined) é passado para setTimeout. Isso não agenda a mensagem corretamente; dependendo do ambiente, a chamada inválida também pode gerar um erro e interromper o script antes de Bye.

Exercício 4. Correção de código

Corrija o código do exercício 3 para que a mensagem passada como parâmetro seja exibida no console apenas após o atraso.

function consoleAtrasado(mensagem, atraso) {
    setTimeout(() => console.log(mensagem), atraso);
}

console.log("Olá");
consoleAtrasado("Teste", 10000);
console.log("Bye");

Resposta: a função deve receber uma função como primeiro argumento de setTimeout. A saída imediata é Olá e Bye; Teste aparece após 10 segundos.

Exercício 5. Qual a versão correta?

Dois colegas seus precisavam escrever um código em JS que deveria escrever "olá" no console e 2 segundos depois escreva "tchau".

Um dos seus colegas escreveu o seguinte código:

const olaTchau = () => {
    console.log("Olá")
    setTimeout(() => console.log("Tchau"), 2000)
}
olaTchau()

Seu outro colega escreveu:

const olaETchau = () => {
    setTimeout(() => console.log("Tchau"), 2000)
    console.log("Olá")
}
olaETchau()

Como os códigos estão diferentes, eles pediram a sua opinião para dizer qual dos dois funciona. Qual deles está certo?

Resposta: os dois estão corretos. Em ambos, Olá é impresso imediatamente e Tchau é agendado para cerca de 2 segundos depois. A ordem entre agendar o temporizador e imprimir Olá não muda esse resultado, pois a chamada síncrona ao console.log termina antes do callback do temporizador.

Exercício 6. Qual a saída no console?

const resolverEm1s = new Promise(resolve => setTimeout(resolve, 1000));
for (let i = 0; i < 10; i++) {
    resolverEm1s.then(() => console.log("oi"))            
}

Resposta: após aproximadamente 1 segundo, oi aparece dez vezes. Os dez callbacks estão registrados na mesma Promise e são executados quando ela é resolvida.

Exercício 7. Qual a saída no console?

const resolverEm1s = new Promise(resolve => setTimeout(resolve, 1000));
for (let i = 0; i < 10; i++) {
    resolverEm1s.then(() => console.log(i))            
}

Resposta: após aproximadamente 1 segundo, aparecem os números de 0 a 9, em ordem. Como i foi declarado com let no cabeçalho do for, cada callback captura o valor da sua própria iteração.

Exercício 8. Qual a saída no console?

let i=0
let max = 10
function p() {
    pp = new Promise(resolve => setTimeout(resolve, 1000))
    pp.then(() => {
        console.log(i++)
        if (i < max) {
            return p()
        }
    })
    return pp
}        
p()

Resposta: a função imprime 0, 1, …, 9, com aproximadamente 1 segundo entre os números. Cada chamada recursiva só é iniciada depois que o temporizador anterior termina.

Exercício 9. Modificação de código

Modifique o código da questão 8 para usar async/await.

const esperar = (ms) => new Promise(resolve => setTimeout(resolve, ms));

async function contarComAsyncAwait() {
    for (let i = 0; i < 10; i++) {
        await esperar(1000);
        console.log(i);
    }
}

contarComAsyncAwait();

Resposta: await pausa a continuação da função assíncrona até cada temporizador terminar, produzindo a mesma sequência de 0 a 9 com um segundo entre os valores.
